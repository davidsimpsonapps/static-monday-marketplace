GraphQL

Get everything you need in one API call

Use GraphQL's nested querying capabilities to get all the data you need in one shot. Just choose your data, write a query, and boom.

[Start building >](https://developer.monday.com/api-reference/docs/introduction-to-graphql)

[](https://dapulse-res.cloudinary.com/video/upload/v1720801883/remote_mondaycom_static/uploads/DiproBhowmik/API-landing-page/key-features-vidoes-v2-july-2024/24_06_09_GraphQL.mp4)

Multiple products, one API

Broad platform coverage to read and modify boards, leads, docs, updates, and much more.

[Start building >](https://developer.monday.com/api-reference/docs/getting-started)

[](https://dapulse-res.cloudinary.com/video/upload/v1720801883/remote_mondaycom_static/uploads/DiproBhowmik/API-landing-page/key-features-vidoes-v2-july-2024/24_06_09_Coverage.mp4)

Set permissions once, use them everywhere

Permissions are unified across APIs, mobile, and the web. You'll never have to worry about a coworker seeing the board for their surprise party again.

[Start building >](https://developer.monday.com/api-reference/docs/authentication)

[](https://dapulse-res.cloudinary.com/video/upload/v1720801882/remote_mondaycom_static/uploads/DiproBhowmik/API-landing-page/key-features-vidoes-v2-july-2024/24_06_09_Security.mp4)

No surprises with a versioned API

Learn about breaking changes in advance so you can adapt accordingly with a predictable version release schedule.

[Start building >](https://developer.monday.com/api-reference/docs/api-versioning)

[](https://dapulse-res.cloudinary.com/video/upload/v1720801882/remote_mondaycom_static/uploads/DiproBhowmik/API-landing-page/key-features-vidoes-v2-july-2024/24_06_09_Versioning.mp4)
