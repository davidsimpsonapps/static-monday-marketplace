# External APIs

For enterprise accounts only, monday.com offers two external APIs to extend platform capabilities.

# SCIM Provisioning API

The [SCIM Provisioning API](https://support.monday.com/hc/en-us/articles/360021893619-SCIM-Provisioning-API) simplifies user and team management with seamless provisioning, de-provisioning, and updates across multiple applications.

# Audit Log API

The [Audit Log API](https://support.monday.com/hc/en-us/articles/4406042650002-Audit-Log-API) gives account admins visibility into audit log events that occur in their monday accounts. It helps monitor account activity, transfer data into other auditing platforms, and detect potential security issues.
