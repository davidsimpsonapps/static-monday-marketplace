# The Developer Center

Learn about managing your API usage in the Developer Center

The Developer Center is a one-stop-shop to manage your [monday apps](https://developer.monday.com/apps/docs/the-developer-center) and API usage. For API users, you can access the API playground, view your API token, and monitor your API usage through the API analytics dashboard.

# Access the Developer Center

1. Open your monday.com account or [sign up for a free developer account](https://developer.monday.com/api-reference/docs/developer-sandbox-account)!
2. Click your profile picture in the top right corner.
3. Select **Developers**.
4. This will open the Developer Center in a new tab.
5. From there, you can navigate to the tabs in the left-side menu to manage your API usage.

# Manage your API usage

## API playground

The *API playground* tab quickly connects you to our authenticated testing space where you can practice API calls, view the schema, and read the documentation. Check out this [video](https://www.youtube.com/watch?v=IHvlag4iFx0\&t=23s) to learn more about the playground!

## API token

You can view or regenerate your API [access token](https://developer.monday.com/api-reference/docs/authentication)  in the *API token* tab.

## API analytics

The *API analytics* tab opens your [API analytics dashboard](https://developer.monday.com/api-reference/docs/api-analytics) where you can track your account's daily API usage, trends, and top contributors.
