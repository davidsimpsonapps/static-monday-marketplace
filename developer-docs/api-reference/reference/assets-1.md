# Assets (files)

Learn how to read, add, and upload assets using the monday.com platform API

Files uploaded to monday.com are saved as [assets](https://support.monday.com/hc/en-us/articles/115005339505-How-to-manage-my-files-in-monday-com), and each asset has a unique ID that identifies it within an account.

# Queries

## Get assets

* **Required scope:`assets:read`**
* Returns an array containing metadata about one or a collection of assets
* Can be queried directly at the root using the `ids` argument or nested within an [`items`](https://developer.monday.com/api-reference/docs/items) or [`updates`](https://developer.monday.com/api-reference/docs/updates) query

```graphql GraphQL
query {
  boards (ids:1234567890) {
    items_page (limit:100) {
      items {
        assets {
          id
          url
          name
        }
      }
    }
  }
}
```
```javascript JavaScript
import { ApiClient } from "@mondaydotcomorg/api";
const mondayApiClient = new ApiClient({ token: myToken });

const query = `query ($boardId: [ID!]) { boards (ids: $boardId) { items_page (limit: 100) { items { assets { id url name } } } } }`;
const variables = {
  boardId: 12345,
};
const response = await mondayApiClient.request(query, variables);
```

### Arguments

| Argument | Type     | Description                     |
| :------- | :------- | :------------------------------ |
| ids      | `[ID!]!` | The asset's unique identifiers. |

## Fields

| Field              | Type      | Description                                                                                                                                                                                              |
| :----------------- | :-------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| created\_at        | `Date`    | The asset's creation date.                                                                                                                                                                               |
| file\_extension    | `String!` | The asset's extension.                                                                                                                                                                                   |
| file\_size         | `Int!`    | The asset's size in bytes.                                                                                                                                                                               |
| id                 | `ID!`     | The asset's unique identifier.                                                                                                                                                                           |
| name               | `String!` | The asset's name.                                                                                                                                                                                        |
| original\_geometry | `String`  | The asset's original geometry.                                                                                                                                                                           |
| public\_url        | `String!` | The asset's public URL (valid for 1 hour). Accessing this link will allow users without a monday.com user profile to see the file directly while the link is valid.                                      |
| uploaded\_by       | `User!`   | The user who uploaded the asset. This field will not return anything if the asset is a duplicate of something generated by a system.                                                                     |
| url                | `String!` | The asset's URL. This will only be available to users who have access to the file through their account. If the asset is stored on a *private* or *shareable* board, it must also be part of that board. |
| url\_thumbnail     | `String`  | The URL to view the asset in thumbnail mode. Only available for images.                                                                                                                                  |

# Mutations

Using the API, you can upload JPEG, Word/Doc, PDF, XLSX, GIF, MP4, CSV, SVG, TXT, and AI files to monday.com. Files are saved as assets and always belong to a parent object (like an item or an update).

<Callout icon="👍" theme="success">
**Files endpoint**

Using the following endpoint, you can upload files up to 500 MB in size via the API: `https://api.monday.com/v2/file`.
</Callout>

### Making multipart requests

If you are making direct requests to the API, you have to use the <a href="https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods/POST" target="_blank">`multipart/form-data`</a> content type, as described in <a href="https://community.monday.com/t/announcement-uploading-files-to-monday-com-has-just-become-easier/16803" target="_blank">our community</a>. Depending on the language or library, you may need to construct the body of the multipart HTTP request manually. Check out a JavaScript example in this <a href="https://community.monday.com/t/uploading-a-file-to-monday-com-with-variables-example-in-nodejs/18526" target="_blank">community post</a>.

## Add file to update

**Required scope:`updates:write`**

Adds a file to the bottom of an update. Returns [`Asset`](https://developer.monday.com/api-reference/docs/files#fields).

```graphql GraphQL
mutation {
  add_file_to_update(
    update_id: 1234567890
    file: YOUR_FILE
	) {
    id
  }
}
```

### Arguments

| Argument   | Type    | Description                                                                                                                         |
| :--------- | :------ | :---------------------------------------------------------------------------------------------------------------------------------- |
| file       | `File!` | The file to upload.                                                                                                                 |
| update\_id | `ID!`   | The unique identifier of the update where the file will be added. You can also use a reply ID to add the file to an update's reply. |

## Add file to column

**Required scope:`boards:write`**

Adds a file to the file column of a specific item. Returns [`Asset`](https://developer.monday.com/api-reference/docs/files#fields).

```graphql GraphQL
mutation {
  add_file_to_column(
    item_id: 1234567890 
    column_id: "files" 
    file: YOUR_FILE
  ) {
    id
  }
}
```

### Arguments

| Arguments  | Type      | Description                                                       |
| :--------- | :-------- | :---------------------------------------------------------------- |
| column\_id | `String!` | The unique identifier of the column where the file will be added. |
| file       | `File!`   | The file to upload.                                               |
| item\_id   | `ID!`     | The unique identifier of the item where the file will be added.   |
