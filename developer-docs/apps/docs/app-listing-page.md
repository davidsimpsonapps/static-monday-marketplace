# App listing page

Learn about the app listing page requirements for listing an app in the marketplace

To receive approval for the app marketplace, your app must meet the following app listing page requirements. Check out our [app listing guidelines](https://developer.monday.com/apps/docs/app-listing-guidelines) for more details about each requirement!

* [ ] Add up to 10 relevant keywords to optimize search results and increase your app’s discoverability.
* [ ] Select up to three predefined categories that your app falls under.
  * CRM
  * Marketing
  * Project management
  * Software development
  * Team management
  * Productivity & efficiency
  * Integrations
  * Collaboration
  * Reporting & analytics
  * Import & export
  * Design & creative
  * HR
  * Finance
* [ ] Write a short description (up to 60 characters) to help users understand the purpose of your app.
* [ ] Write a long description (200-2,500 characters) to convey your app’s functionality, features, and value.
* [ ] Create one image (592x348 pixels) to include on the app card that highlights your app's key features.
* [ ] Provide an app icon (192x192 pixels) to display in the marketplace.
* [ ] Provide a developer icon (192x192 pixels) that will appear in the developer section.
* [ ] Include 3-5 images (1920x960 pixels) to highlight your app in the photo gallery.
* [ ] Create a video of up to 120 seconds that demonstrates the app’s key benefits, features, functionality, UI, and UX. The file should be 50 MB or less.
* [ ] For **workspace templates**, set up a [demo experience](https://developer.monday.com/apps/docs/demo-experience) app feature.
