# Demo experience

The guide dives into the marketplace demo experience, its benefits, how to use it, and frequently asked questions.

The new marketplace demo experience provides a test environment where monday.com users can try certain workspace template apps before subscribing. With just the click of a single button, users can see the app's capabilities first-hand (and commitment-free) to help make better-informed decisions with minimal effort.

# Benefits

The demo experience helps create a user-friendly, secure, and efficient app selection process that benefits users and developers alike by:

* Helping users get value from your app faster
* Improving quality of app installations
* Building confidence in apps with insignificant ratings or installations
* Boosting your app's prominence in the marketplace
* Reducing subscription cancellations for instances where the app does not fit a user's needs

# How it works

The demo experience is only available for marketplace apps. It works with any workspace template app feature, though we recommend using an optimized template that immediately highlights your app's core functionality and capabilities.

After creating a new app feature or selecting an existing one, you can set it as the demo feature in a new minor app version. Once you promote this version to live, this feature will be available for all users to demo in the marketplace.

Once live, the app listing card will contain a button to try the app in the testing environment. Each user will have an individual temporary test account where they can try the app for 24 hours. If two users from the same account try the demo experience, they will have two separate test accounts.

You will not be automatically enrolled in this feature and must opt-in using the steps below.

## Set a demo experience app feature

1. Click your profile picture in the top right corner.
2. Select **Developers**. This will open the Developer Center in another tab.
3. Select your app and navigate to the *Features* tab on the left-side menu.
4. Click the **three dots** next to the workspace template app feature you'd like to use for the demo experience.
5. Select **Set as demo**.

# Frequently asked questions

### Does the demo experience limit my app's functionality?

Each app feature has full functionality inside the test environment to highlight what it can do.

### Do demo experiences go through a review or approval process?

No, unless you create a demo experience as part of your first submission to the marketplace.

### Can I track user interactions within the demo experience?

No. Demo experience users have not installed the app yet or provided consent to share data with developers.

### If users haven't given consent to share data, how does the app access their account info?

The demo experience utilizes temporary test accounts instead of user data. Users don't need to request admin approval and can begin testing immediately

### What metrics should I monitor for the demo experience?

We recommend measuring the conversion rate from the initial app view to installation.
