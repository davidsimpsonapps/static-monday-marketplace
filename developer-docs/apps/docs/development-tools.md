# Development tools

monday.com provides a set of development tools to help you build, manage, and design apps efficiently. These tools help streamline the app development process — from writing and testing code to building interfaces that align with the platform's look and feel.

* **[Command line interface (CLI):](https://developer.monday.com/apps/docs/command-line-interface-cli)** A collection of predefined terminal commands for interacting directly with the apps framework.
* **[Software development kit (SDK):](https://developer.monday.com/apps/docs/introduction-to-the-sdk)** A JavaScript toolset for building apps on top of the monday.com platform.
* **[Vibe design system:](https://developer.monday.com/apps/docs/vibe-design-system)** monday.com's UI component library that ensures visual and functional consistency across apps.
