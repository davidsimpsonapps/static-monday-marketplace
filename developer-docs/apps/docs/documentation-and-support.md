# Documentation and support

Learn about the documentation and support requirements for listing an app in the marketplace

To receive approval for the app marketplace, your app must meet the following documentation and support requirements:

* [ ] Select your [pricing method](https://developer.monday.com/apps/docs/plans-and-pricing#types-of-plans).
* [ ] New marketplace apps must be monetized by monday (read more [here](https://developer.monday.com/apps/changelog/new-monetization-requirements-for-marketplace-approval)).
* [ ] Provide an email address or feedback URL so marketplace users can contact you.
* [ ] Add a demo link to check your app’s flow (this is only for the app review process—it will not be shared in the marketplace).
* [ ] Share your website link.
* [ ] Add all relevant email addresses to the shared board (this is only for the app review process—these will not be shared in the marketplace).
* [ ] Create a how-to-use page to share helpful information about your app with users after installation. Following the HTTPS protocol, you must provide an embeddable link to an iframe for the \*.monday.com domain.

  The page should include installation instructions, prerequisite information, first-time-use instructions, and images and videos to support your app. It should also be cleaned to prevent navigating to other pages on the website. You can test whether or not the URL can display in an iframe using an <a href="https://iframetester.com/" target="_blank" rel="nofollow">iframe tester</a>.
