# Host your app on monday code

Discover the capabilities of the monday code hosting platform

monday code is a secure, scalable, low-code platform for hosting and running apps directly within monday.com's infrastructure. It complies with enterprise-grade security standards, including GDPR, HIPAA, ISO 27001, and SOC 2.

Currently, hosting your app on monday code is offered free of charge, though it may be subject to payment in the future.

# Why use monday code?

Seamlessly integrated with the monday apps framework, monday code provides a complete toolkit for developing, deploying, and managing your app—without leaving the monday.com ecosystem.

You get:

* 🔐 Secure hosting environment
* 💻 [Command line interface (CLI)](https://developer.monday.com/apps/docs/command-line-interface-cli)
* 📦 [JavaScript](https://developer.monday.com/apps/docs/monday-code-javascript-sdk) and [Python](https://developer.monday.com/apps/docs/monday-code-python-sdk) SDKs
* 🚀 [Quickstarts](https://developer.monday.com/apps/docs/deployment-process#quickstarts-in-other-languages) in multiple languages
* 💡 [Kitchen sink app](https://github.com/yuhgto/monday-kitchen-sink/blob/main/README.md)
* 🌍 [Multi-region](https://developer.monday.com/apps/docs/multi-region-feature) support
* 🛡️ [Network protection and management](https://developer.monday.com/apps/docs/manage-your-apps-outbound-communication)
* 🗝️ [Key-value storage](https://developer.monday.com/apps/docs/monday-code-javascript-sdk#storage)
* 🔐 [Secret storage](https://developer.monday.com/apps/docs/monday-code-javascript-sdk#secure-storage)
* 🧪 [Environment variables management](https://developer.monday.com/apps/docs/monday-code-javascript-sdk#environment-variables-manager)
* 📣 [Pub/sub queue](https://developer.monday.com/apps/docs/monday-code-javascript-sdk#queue)
* 📊 [Logging](https://developer.monday.com/apps/docs/manage-monday-code-in-the-developer-center#logs), [monitoring](https://developer.monday.com/apps/docs/manage-monday-code-in-the-developer-center#monitoring), and [alerting](https://developer.monday.com/apps/docs/manage-monday-code-in-the-developer-center#alert-policies-tab) tools
* :calendar: [Job scheduler](https://developer.monday.com/apps/docs/schedule-cron-jobs-in-monday-code)
* :file\_folder: [Document DB](https://developer.monday.com/apps/docs/document-db)
* :eyes: [Security scanning](https://developer.monday.com/apps/docs/security-scanning)
* :file\_cabinet: [Object storage](https://developer.monday.com/apps/docs/object-storage)

# App limits

You can connect unlimited marketplace apps and up to 10 private apps to monday code.

# Restrictions
