# Partner Page

Every marketplace partner has a dedicated Partner Page to highlight their app portfolio, partner program status, performance metrics, and contact information. This page is designed to build user trust and boost app installs by providing a transparent look into the partner's history, performance, credibility, and products.

# Concepts

The Partner Page is a centralized location in the marketplace where users can explore key details about each partner. It showcases app performance data, partner achievements, product portfolios, trust signals, and contact information.

This page is automatically created for **all** marketplace partners—no application or opt-in is required.

Users can access the page by clicking the developer name beneath the app's title on the app listing page. It's available in both the [public marketplace](https://monday.com/marketplace/) and to signed-in users.

By offering more transparency, the Partner Page helps increase trust and credibility with users, helping drive more app installs. For developers, it also serves as a shareable portfolio accessible via a direct URL.

# Page elements

Every Partner Page contains the following elements:

| Category                              | Description                                                                                                                           |
| :------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------ |
| **Partner information**               | Contact details, [app categories](https://developer.monday.com/apps/docs/app-listing-page) , and relevant external links              |
| **Key performance indicators (KPIs)** | Marketplace join date, total installs across all apps, and average app rating                                                         |
| **Partner portfolio**                 | A complete list of the partner's marketplace apps, sorted by rating                                                                   |
| **Program participation and badges**  | Displays your [partner program status](https://developer.monday.com/apps/docs/marketplace-programs#partner-program) and earned badges |
