# Sales

Learn how to track your app’s revenue performance with metrics like ARR, MRR, and active subscriptions

Apps monetized through monday can access sales and subscription analytics in the *Sales* tab. This dashboard compiles key metrics, like ARR, MRR, and subscription data, into one easy-to-access location within the Developer Center UI.

The *Sales* tab is only visible for apps using [monday's native monetization](https://developer.monday.com/apps/docs/monetization). Most widgets refresh daily to provide up-to-date insights, and you can see the last updated timestamp in the top-right corner of each widget.

These metrics help you make informed decisions to boost app sales, retain customers, and succeed in the marketplace. Sales analytics are only available in the Developer Center UI, not via the API.

<Callout icon="👍" theme="okay">
  Hover over any ⓘ icon in the dashboard to view detailed explanations for each metric.
</Callout>

# Export the Data

You can export data from many widgets on the *Sales* page as a CSV file for further analysis or sharing.

To export:

1. Navigate to the *Sales* tab.
2. Click the **three dots (…)** in the top-right corner of the relevant widget.
3. Select **Download CSV**.
4. Open the CSV file from your local device.
