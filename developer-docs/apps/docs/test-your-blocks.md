# Test your blocks

Learn how to test your blocks using an active app version

You can test your blocks in your monday.com account before releasing them to end users. For testing, we recommend using the active app version, which reflects the current production-ready configuration of your app in your account. Learn more about how the active version works [here](https://developer.monday.com/apps/docs/app-versioning#test-an-app-feature-with-an-active-version).

1. Open your app in the *Developer Center*.
2. Under *Manage*, select **App versions**.
3. Ensure the version containing the blocks and fields you want to test is set as the [active version](https://developer.monday.com/apps/docs/app-versioning#test-an-app-feature-with-an-active-version).
4. Open the workflow builder and add your blocks to a workflow.
5. Trigger the workflow to validate your block behavior and data flow.
