# UI/UX

Learn about the UI/UX requirements for listing an app in the marketplace

To receive approval for the app marketplace, your app must meet the following UI/UX requirements:

* [ ] Use lowercase m's when referring to monday.com.
* [ ] Perform most actions in 0.5 to 1 second. If it takes longer, visually show progress to the user.
* [ ] Use monday’s settings, search bar, and filters. Refer to our <a href="https://style.monday.com/?path=/story/welcome--page" target="_blank">design system</a> for more information.
* [ ] Add tooltips, hints, banners, or any other assistive components that can be helpful while using your app for **board views**, **item views**, and **dashboard widgets**. Make **integration recipe** wording as concise as possible so the user clearly understands what the trigger and action are.
* [ ] Include a welcome page that displays before the app's main page for **board views** and **widgets**. It should include a welcome message, first-time-use instructions with screenshots, and any necessary data the user should know before using the app. This page is not required for recipes.
* [ ] Ensure that your app supports multiple modes, such as light mode, dark mode, or night mode. If not, verify that app functionality is not affected by it.
