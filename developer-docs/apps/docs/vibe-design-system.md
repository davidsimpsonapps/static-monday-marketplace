# Vibe design system

The [Vibe design system](https://vibe.monday.com) is monday.com's user interface (UI) library for app development in React.js. It contains a set of design guidelines and UI components that you can leverage to design a monday.com-inspired app.

The system is a powerful resource to build your app with user engagement and experience in mind. It provides a cohesive experience across your app and the platform itself.

The library contains over 50 components related to theming, data display, accessibility, navigation, layout, media, feedback, inputs, text, buttons, popovers, media, pickers, and hooks.

Each component has documentation that covers properties, usage, variants, do's and don'ts, use cases, and examples to help streamline app development. Check out the [Vibe site](https://vibe.monday.com) or [Github](https://github.com/mondaycom/vibe) to get started!
