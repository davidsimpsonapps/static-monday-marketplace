# Example apps

Explore example apps built by the monday.com team

These examples can used as a starting point for building your own apps or as concrete examples of how to use our monday apps framework.

> 👍
>
> You can access all of our sample apps by cloing this Github [repo](https://github.com/mondaycom/welcome-apps/).

# View app

This is an example board view app based on React. It will show you how to build a simple board view and use the view settings to reflect changes in your board view. Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/quickstart-react)!

# Integration app

This is an example integration recipe app based on Node.js. The recipe allows you to change the case of text stored in a text column in a separate text column on a board. Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/quickstart-integrations)!

# GitHub integration

This example GitHub integration app consists of two board recipes: "Create an issue in a selected repository after a status change on a monday.com board" and "When an issue is created in a repository, create an item." Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/github-node)!

# Word cloud

This example board view renders the word cloud based on the frequency of the words in your board. You can load column data from one of your boards to generate a word cloud, and you can also play around with the padding for the word cloud as well. Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/word-cloud)!

# Online docs viewer

This example board view can open your documents directly within monday.com. It also allows you to embed a website directly into your board with the website URL. Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/docs-viewer)!

# Slack integration

This example Slack integration recipe allows you to post in a Slack channel each time an update is created on one of your monday.com boards. Access the project [here](https://github.com/mondaycom/welcome-apps/tree/master/apps/slack-node)!
