date: 2026-09-09

lede: "Two new apps: AI Doc from RasilStar builds documents from board data, and Gantt Dependencies from Unitask Ltd reschedules dependent tasks when dates change."
---

[AI Doc](/apps/10001261/) generates formatted documents such as reports, invoices, proposals and contracts from board data, using templates and column tags that also cover subitems and file columns. Documents can be created by automations on new items, status changes or button clicks, exported as PDF or Word, or saved to a file column. The vendor states that it uses the Groq and Google Gemini APIs for generation.

[Gantt Dependencies](/apps/10001272/) turns monday's Dependency column into a scheduler for finish-to-start chains. When a task's timeline or date changes, every dependent task is recalculated from its predecessor's end date, using columns for duration, lag and working days. It is set up through automation recipes and can also be run as a Sidekick skill. Accounts start on a free plan.
