date: 2026-11-02

lede: "TestBoard by Aisly Apps is a new marketplace app for managing test cases, test cycles and results inside monday.com. It is aimed at QA teams, developers and product teams."
---

[TestBoard](/apps/10001238/) lets users write test cases, group them into test sets, link them to board items and run them in test cycles, recording pass or fail results for each step. Bugs can be reported from test steps, and the app can generate test cases with AI.
