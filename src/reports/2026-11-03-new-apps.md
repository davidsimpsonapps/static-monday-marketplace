---

[Translate Document](/apps/10000965/) by Otomo Solutions translates files attached to items on a board using DeepL. Users choose source and target languages, can adjust formality for some languages, and the result is added to the board. It supports Word, PowerPoint, Excel, PDF, text, HTML, XLIFF and SRT files.

[AI Doc](/apps/10001261/) by RasilStar builds documents such as reports, invoices, proposals and contracts from board data, using templates and AI-generated content. Documents can be exported as PDF or Word, or saved to file columns, and automations can create them on triggers such as a new item or status change.

[QuickBooks Desktop Integration](/apps/10001278/) by Boost Plugins Inc. embeds the Accounting Relay dashboard in monday.com so teams can browse QuickBooks Desktop bills and invoices and export selected records to a board, with field-to-column mapping. It requires a subscription.
